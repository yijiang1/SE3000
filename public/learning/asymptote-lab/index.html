What is a rational function?

It's just a fraction made of polynomials: P(x)Q(x) where the bottom Q(x) is not the zero polynomial. You can plug in any x that doesn't make the bottom equal 0.

An asymptote is a line that the graph gets closer and closer to, without (usually) ever settling on it. There are three kinds:

🧱 Vertical
A wall at x = a. Graph shoots up or down forever beside it. Comes from the bottom = 0.
🌅 Horizontal
A flat line y = b the graph hugs far to the left/right. Comes from comparing degrees.
📐 Slant
A tilted line y = mx + b the graph hugs far out. Happens when the top is exactly 1 degree bigger.

🧱 Vertical asymptotes: invisible walls

You can't divide by zero. So if some x makes the bottom 0, the function is undefined there. Near that x the bottom is tiny, and a number divided by something tiny is enormous. The graph rockets up or down along an invisible wall. That wall is a vertical asymptote.

Big catch: if the same factor also sits on top, it cancels, and you get just a hole (open circle), not a wall.

⚠️ Common mistakes

  • Setting the top equal to 0. That gives x-intercepts, not asymptotes.
  • Forgetting to cancel first. A factor on both top and bottom is a hole.
  • Thinking x² + 1 = 0 gives a wall. It has no real solution, so no wall.

🌅 Horizontal asymptotes: where the graph heads at the far ends

Imagine walking far to the right (or left) along the graph. A horizontal asymptote y = b is the height the graph settles toward. It only cares about big |x|, so only the highest powers matter. Just compare the degree of the top and the bottom.

📐 Slant (oblique) asymptotes: a tilted horizon

When the top is exactly one degree bigger than the bottom, the graph doesn't flatten out. It follows a tilted line. To find it, divide the top by the bottom. The quotient is the line, and the leftover remainder fades away for large |x|.

P(x)Q(x) = (mx + b) + remainderQ(x)   → the fraction part shrinks to 0, leaving y = mx + b.

➗ Synthetic division: a shortcut for dividing by (x − c)

It's long division with all the x's removed, so you only juggle the coefficients. It works whenever the divisor looks like x − c. (For x + 3, use c = −3.)

The 3-beat rhythm

Bring down the first number → multiply by c and write it under the next number → add the column. Repeat. The last total is the remainder; the others are the quotient's coefficients (one degree lower than the original).

Don't skip zeros! If a power is missing (like x⁴ in x⁵ + x³ − x²), write a 0 for it.
